1. PRODUCT IDENTITY & MISSION
--------------------------------------------------------------------------------
ellmos-ai.github.io serves as the official interactive public showcase and web gateway
to the ellmos modular AI framework and open-bricks ecosystem. It presents interactive
visual circuit diagrams, modular composition recipes, a full public skill catalog,
and a visual stack composer for software engineers and autonomous AI agents.

Key Portal Components:
  1. Module Circuit Map (index.html):
     Visual circuit diagram of all public modules categorized by functional domain
     (DE/EN, dark/light themes, offline interactive filtering).
  2. Bundle Recipes (bundles.html):
     13 curated composition recipes detailing which modules, skills, and tools
     form each functional bundle with explicit requirement levels.
  3. Skill Library (skills.html):
     Public SKILL.md library with integrated viewer and one-click copy-to-clipboard.
  4. Stack Composer (stack-composer.html):
     Interactive canvas to assemble custom module stacks with live composition-rule
     validation and stack.v2.json export.

2. TARGET PERSONAS & AUDIENCE MAPPING
--------------------------------------------------------------------------------
Persona 1: Autonomous AI Agent Architects & Operators (Gemini, Claude Code, Codex)
  - Need: Machine-readable component schemas, skill documentation, and stack specifications.
  - Value: Direct access to llms.txt, standardized public SKILL.md documents, and
    deterministic stack.v2.json export formats.

Persona 2: Modular System Engineers & Developers
  - Need: Understanding how independent modules (MCP servers, hooks, proxies, runners)
    wire together without having to read dozens of disparate README files.
  - Value: Visual circuit map showing dependencies, communication protocols, and
    interactive stack composition with real-time rule checking.

Persona 3: Security & Privacy Officers
  - Need: Ensuring that web dashboards and developer portals do not leak telemetry,
    track users, or introduce supply-chain CDN vulnerabilities.
  - Value: 100% static, self-contained architecture with zero external requests,
    zero analytics, and automated fail-closed leak-gates blocking non-public IDs.
